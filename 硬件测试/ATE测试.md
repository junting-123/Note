# ATE测试入门教学

`ATE测试简单来说就是为了测量芯片的物理量是否符合标准，例如电压、电流、频率等等`

# 一、IC测试理论
## 1.IC芯片测试的原理

1. 测试目的

   IC测试的目的主要是将合格的芯片与不合格的芯片区分开，保证产品的质量与可靠性。

   其过程是将封装后的芯片置于不同环境条件下，检测其功耗、运行速度、耐压等电气特性。根据测试结果，芯片会被划分为不同的性能等级。针对客户的特殊需求，还会进行专项测试：从相近规格、品种的芯片中挑选样品，依据客户提供的技术参数进行针对性验证。此举旨在判断现有芯片能否满足客户的特定要求，从而决定是否需要为其定制专用芯片。

   一般测试合格的产品，会粘贴标注规格、型号及生产日期的标签，经包装后即可出厂。未通过测试的芯片，则根据其实际达到的参数水平，被定为降级品或作废品处理。

2. 测试原理

   IC 测试是指依据**被测器件（DUT）特点和功能**，**给DUT提供测试激励（X）**，通过测量DUT **输出响应（Y）**与期望输出做比较，从而判断DUT是否符合格。

3. 测试分类

   IC测试可以分为数字电路测试、模拟电路测试和混合电路测试。

   数字电路测试是IC测试的基础，数字IC 测试一般有直流测试、交流测试和**功能测试**。

   - 直流参数测试

     直流参数测试（DC）是检查芯片在**静止**状态下的电气特性（比如漏电、驱动能力、功耗）。基于欧姆定律的，用来确定器件参数的稳态测试方法。

     测试包括：接触测试、漏电流测试、转换电平测试、输出电平测试、电源消耗测试等。通过直流测试可以判明电路的质量。如通过接触测试判别IC引脚的开路/短路情况、通过漏电测试可以从某方面反映电路的工艺质量、通过转换电平测试验证电路的驱动能力和抗噪声能力。

     直流测试是IC测试的基础，是检测电路性能和可靠性的基本判别手段。

   - 交流参数测试

     交流参数测试（AC）是检查芯片在**动态**作时的时序和速度特性（比如信号能跑多快、延迟多久）。是以时间为单位验证与时间相关的参数，实际上是对电路工作时的时间关系进行测量。

     常见的测量参数有上升和下降时间、传输延迟、建立和保持时间以及存储时间等。交流参数最关注的是最大测试速率和重复性能，然后为准确度。

   - **功能测试**

     **功能测试用于验证IC是否能完成设计所预期的工作或功能。**它模拟IC的实际工作状态，输入一系列有序或随机组合的测试图形，以电路规定的速率作用于被测器件，再在电路输出端检测输出信号是否与预期图形数据相符，以此判别电路功能是否正常。

     功能测试一般在ATE（Automatic Test Equipment）上进行，**ATE测试可以根据器件在设计阶段的模拟仿真波形，提供具有复杂时序的测试激励，并对器件的输出进行实时的采样、比较和判断。**

     

# 二、ATE测试理论
## 1.ATE测试理论
ATE系统组成

ATE是自动测试设备，是一个集成电路测试系统。代替人工，在极短时间内自动完成对芯片所有性能的全面检查。一般包含

**ATE系统 = (测试机 + 测试头) 作为通用测控核心 + (Loadboard/ProbeCard/Socket) 作为定制接口 + (操作台) 作为机械支撑 + (软件) 作为大脑**



1. 测试机—— “大脑”

   *这是ATE系统的核心主机，通常是个大型机柜*

   - 精密测量单元：负责DC参数测试（电压/电流/电阻）。
   - 数字通道卡：负责AC参数、功能测试，产生高速时钟和向量。
   - 电源：为被测芯片提供稳定、可编程的电压（DPS）。
   - 高速总线/背板：用于内部数据传输。
   - 主控计算机：运行测试程序，控制整个测试流程。

   

2. 测试头—— “手脚”

   *测试头是一个圆形或方形的金属/塑料罩子，通过电缆与测试主体相连*

   

3. 操作台/机械手接口——连接

   *用来支撑和移动沉重的测试头*

   - 操作台：一个带有气动或液压臂的支架。工程师用它来**抬起、平移、旋转**测试头，使其精确对准并**下压对接**到Handler（自动分选机：自动抓取、放置、分类封装好的芯片）或Prober（晶圆探针台：自动移动晶圆并实现定位）上。
   - 对接环：安装在测试头或Handler/Prober上的金属环，带有导销，确保测试头每次都能精确、可重复地与下方设备连接。

   

4. 测试接口硬件——定制化的“转接器”

   *这是ATE中唯一需要根据具体芯片定制的部分。它连接测试头与芯片。*

   **关系**：`测试头 → Loadboard(负载板)/ProbeCard(探针卡) → Socket(测试座)/Probe → 芯片`

<img src="https://cdn.jsdelivr.net/gh/junting-123/my-blog-images/img/20260429162603343.png" alt="image-20260429162548392" style="zoom:50%;" />

5. 软件和操作系统——灵魂

   - **操作系统**：通常运行在Windows或Linux上的实时系统。

   - **开发环境**：工程师编写测试程序的平台。例如 Teradyne 的 **IG-XL**， Advantest 的 **SmarTest**， NI 的 **TestStand**。

   - **测试程序**：你写的代码（通常用C++， Python或专用语言）。它控制：

     a. 给芯片提供多少电压/时钟频率。

     b. 哪个PMU测量什么。

     c. 向量时序（何时Force，何时Compare）。

     d. 如何判定Pass/Fail，以及良率计算。

     e. 调试工具：波形显示、Shmoo图绘制、数据记录等交互式工具。



## 2.CP测试

​	1. CP测试（Circuit Probing、Chip Probing）也称为晶圆测试或中测。

​	测试对象是整片晶圆（wafer）的每一个芯片（Die），主要是**用探针扎晶圆上的裸芯片，在封装前就把坏的筛掉**，通常包括电压、电流、时序和功能的验证。初步筛选出不良的DIE，可以减少封装和测试的成本，同时优化生产流程，提高良品率在CP测试过程中。

2. 测试流程

   全自动探针测试台自动上下片，操作员只需要将晶圆放到预对准台做好预对准，再将片子送达承片台上等待主机部分处理。同时它也将主机测试完成的片子送回到料盒中。

   <img src="https://cdn.jsdelivr.net/gh/junting-123/my-blog-images/img/20260429162730556.png" alt="image-20260429162729449" style="zoom: 33%;" />

CP测试完成后，会生成两类重要的输出：测试数据（Datalog）和晶圆图（Wafer Map，简称MAP）。

**测试数据（Datalog）**
这是一份详细的测试报告，通常以单个裸片（Die）为单位进行统计，包含以下信息：

- **位置信息**：每个Die在晶圆上的具体位置，通常用X、Y坐标表示。
- **测试项目**：对每个Die执行的测试，可能包括电压、电流、时序、功能测试等。
- **测试结果**：每个测试项目的结果，通常用PASS（通过）或FAIL（失败）表示，其中FAIL品也被称为REJECT。
- **分BIN信息**：根据性能或质量等级对Die进行分类的结果。

**晶圆图（Wafer Map，简称MAP）**
这是一张图形化的表示方式，能够直观展示整片晶圆的良率分布，通常包含以下信息：

- **分BIN显示**：在MAP上，测试合格的Die会按照不同BIN分类显示，分类依据可以是性能、质量或其他测试标准。
- **Hard Bin（硬分类）**：严格按照测试标准进行划分的BIN，通常直接反映Die是否能正常工作。
- **Soft Bin（软分类）**：与Hard Bin相对，Soft Bin中包含的是性能稍差、或有轻微缺陷但可能仍可使用的Die。是否采用Soft Bin，取决于具体的应用需求和成本考量。
- **封装依据**：MAP为后续封装环节提供关键信息，用于筛选合格的Die进行封装，有助于优化封装流程，确保最终产品的质量和性能。

## 3.FT测试
1. **FT测试**（**Final Test**），简单说就是芯片已经封装成我们平时看到的那种黑色小方块之后，进行的最后一道测试。FT测试是确保芯片在最终封装形态下的功能和性能符合设计规范的重要步骤。

   芯片在晶圆上考完了基本科目（CP测试），然后切出来、封装好，变成了成品。这时候，需要通过FT测试来最后确认一下，这颗成品芯片是不是真的能干活、性能达不达标。

   具体来说，FT测试有这样几个特点：

   1. **测试样品**：

      测的是封装好的成品芯片。这时候芯片已经有外壳和引脚了，不像CP测试时那样是裸露的。

      

   2. **测试目的**：

      这是芯片出厂前的最后一道关口。就像产品出厂前的最终质检，确保每一颗卖给客户的芯片都是好用的，功能和性能都符合设计要求。

      

   3. **测试内容**：

   - **环境测试**：在模拟实际使用条件下进行的测试，如高温、低温、湿度等环境因素对芯片性能的影响。
   - **老化测试**：通过在加速应用条件下对芯片进行长时间运行，来模拟其在实际使用中的老化过程。这可以帮助预测芯片的寿命和可靠性。
   - **应用特定的性能测试**：根据芯片的最终应用来设计的测试，确保其在特定应用中的性能。这可能包括电气参数测试、功能测试、信号完整性测试等。
   - **数字和模拟电路测试**：测试内容包括数字逻辑功能、模拟信号处理能力以及混合信号电路的性能。
   - **OS测试**：开路（Open）和短路（Short）测试，用于检测芯片的引脚是否存在开路或短路问题，这对于确保芯片封装质量至关重要。

   

   4. **测试设备**：

      主要用两台机器配合。一台是**ATE测试机**，它负责产生测试信号、判断芯片反应对不对，相当于“考官”；另一台是**Handler（分选机）**，它是个“机械手”，负责自动把芯片抓过来放进测试座、测试完再按结果分门别类，相当于“考场工作人员”。

      

   5. **测试结果**：

      根据FT测试的结果，芯片会被分成不同等级。完全通过的，就是良品，可以出货；没通过的，就是不良品，会被淘汰。有些性能有好有坏的（比如同一种芯片有的跑得快、有的跑得慢），还会根据测试结果分成不同档次，卖不同的价格。

      

   6. **重要性**：

      因为这是最后一道防线了。假如封装好了才发现芯片有问题，那前面的封装成本就全浪费了，而且如果坏芯片流出到客户手里，会造成更严重的损失。所以FT测试对保证产品质量、保护公司声誉非常关键。
